# wormt blog

[This website](https://brainworm.homes/) is built by a blog generator I wrote. Roc lang is used for HTML, Dart Sass for CSS, Nix+Fedora bootc for the OS, and Java+Pulumi for deploying the bootc image to Azure. There is also a script written in Racket for SSL certificate management.
